# Source data

- `009826_twse.csv`: TWSE 個股日成交資訊，009826，2026-08 與 2026-09 分月查詢。
- `vt_vanguard.csv`: Vanguard 官方 VT「Historical prices」表格，擷取每日市場收盤價。
- `usdtwd_cbc.csv`: 中華民國中央銀行「NT$/US$ Closing Rate」。

擷取日期：2026-09-01 UTC。資料以單一月份／單一標的分次取得，避免大量請求。共同完整收盤資料截至 2026-08-31。

2026-08-03 至 2026-08-31 期間 VT 沒有除息；此期間市場收盤價報酬與含息調整價格報酬一致。跨越未來除息日時，需加入配息再投入計算後才可稱為總報酬。
